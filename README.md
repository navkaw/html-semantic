# Task: Semantic Page

Це твоє перше завдання — вітаю! 🚀
Мета цього завдання — перевірити, як ти розумієш семантичну HTML-структуру, block / inline елементи.

# 📌 Вимоги

- Структура повинна містити такі семантичні теги:
```
<header>
<nav>
<main>
<section>
<article>
<aside>
<footer>
```

- header повинен містити:
1. Заголовок сайту
2. Короткий опис
3. Навігаційні посилання

- main повинен містити:
1. Окремі Секції
2. Заголовки у кожній з них
3. Параграфи з текстом
4. Списки

- footer повинен містити:
1. Назва сайтів які ти використовувала
2. Поточний рік
3. Твоє ім'я та час за який ти впоралась
